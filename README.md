# 🌱 成长小记

6 岁孩子每日学习与启蒙记录 App（纯前端、离线可用、数据存在本机）。

## 功能

- **7 个预置大类**：运动🏀、英语🔤、古诗📜、识字🔡、阅读📚、声乐🎵、口才🎤
- **大类下可无限新增小类**：英语→阅读/听力/口语/视频；运动→篮球/街舞/跳绳……
- **每条记录必填时长（分钟）**，并填写事项内容（如"跳绳100个"）+ 日期
- **图形统计**：日 / 周 / 月 三档切换
  - 汇总卡片（总时长、记录数、涉及分类、天数）
  - 分类占比**环形图**
  - 每日 / 各分类时长**柱状图**
  - 时长**折线趋势图**
- **设置页**：分类与小类的增删改名、数据导出/导入 JSON 备份、一键清空

## 使用方法

这是一个纯静态网页（无需服务器、无需联网）：

1. 直接用浏览器打开 `index.html` 即可使用；
2. 手机上：把文件传到手机后用浏览器打开，或用浏览器菜单「添加到主屏幕」，即可全屏像原生 App 一样使用。

数据保存在**本机浏览器**（localStorage），不会上传到任何服务器。换设备 / 清缓存 / 换浏览器前，请在「设置 → 导出数据」备份。

## 部署到 GitHub Pages

仓库根目录即为站点根目录。在仓库 **Settings → Pages** 中选择：
- Source：`Deploy from a branch`
- Branch：`main` / `master`，目录：`/ (root)`

保存后访问 `https://<用户名>.github.io/<仓库名>/` 即可。
